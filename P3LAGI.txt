    1. UPDATE PAKET UBUNTU

    sudo apt update -y


    2. INSTALL MARIADB SERVER DAN CLIENT

    sudo apt install mariadb-server mariadb-client -y


    3. AKTIFKAN MARIADB

    sudo systemctl enable --now mariadb


    4. PERIKSA STATUS MARIADB

    sudo systemctl status mariadb

    Pastikan status menunjukkan active (running).


    5. AMANKAN MARIADB

    sudo mariadb-secure-installation

    Pilihan konfigurasi:
    - Switch to unix_socket authentication: Y
    - Change root password: N
    - Remove anonymous users: Y
    - Disallow root login remotely: Y
    - Remove test database: Y
    - Reload privilege tables: Y

    Buat file PHP:

    sudo nano /var/www/ukom12tkja-17.sch.id/database.php

    Isi file dengan kode berikut:
<?php
$host = "localhost";
$user = "ukom17";    
$password = "UkomDB@2026";
$database = "ukom17";

$conn = new mysqli($host, $user, $password, $database);

if ($conn->connect_error) {
http_response_code(500);
error_log("Koneksi database gagal: " . $conn->connect_error);
exit("Koneksi database gagal.");
}

$conn->set_charset("utf8mb4");

echo "<h1>Koneksi Database Berhasil</h1>";

$sql = "SELECT * FROM informasi";
$result = $conn->query($sql);

if ($result && $result->num_rows > 0) {
while ($row = $result->fetch_assoc()) {
echo "<hr>";
echo "ID: " . htmlspecialchars($row["id"]) . "<br>";
echo "Nama: " . htmlspecialchars($row["nama"]) . "<br>";
echo "Keterangan: " . htmlspecialchars($row["keterangan"]) . "<br>";
echo "Dibuat: " . htmlspecialchars($row["created_at"]) . "<br>";
}
} else {
echo "Tidak ada data.";
}

$conn->close();
?>

    Catatan: Password PHP harus sama dengan password user database pada langkah 8, yaitu UkomDB@2026.

    reload Apache:

    sudo systemctl reload apache2

    20. BUAT KONFIGURASI DOMAIN

    Buka file:

    sudo nano /etc/apache2/sites-available/ukom12tkja-17.sch.id.conf

    Isi konfigurasi:

<VirtualHost *:80>
    ServerName ukom12tkja-17.sch.id
    ServerAlias www.ukom12tkja-17.sch.id
    ServerAlias 100.100.17.2

    DocumentRoot /var/www/ukom12tkja-17.sch.id

    <Directory /var/www/ukom12tkja-17.sch.id>
        Options FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/ukom17-error.log
    CustomLog ${APACHE_LOG_DIR}/ukom17-access.log combined
</VirtualHost>

    Buat direktori dan aktifkan situs:

    sudo mkdir -p /var/www/ukom12tkja-17.sch.id
    sudo a2ensite ukom12tkja-17.sch.id.conf
    sudo apache2ctl configtest
    sudo systemctl reload apache2

    Pastikan hasil pemeriksaan konfigurasi menunjukkan Syntax OK.
